## New config keys and secrets

- Secret `ADMIN_PASSWORD`. Locally in `.dev.vars` (git-ignored). This
  session created `.dev.vars` in the project folder with a random
  40-character password; read it there or replace it.
- `astro.config.mjs` `session` block (above). Astro sets the session cookie
  `httpOnly` itself and does not accept the option; the response header was
  checked: `HttpOnly; Secure; SameSite=Lax; Max-Age=2592000`.

## Decisions

- **Decision H**: the `/admin` dashboard is built now, because it is the
  page after login. Order figures stay at zero until M4.
- **Password check** uses `crypto.subtle.timingSafeEqual` as the plan says.
  The Workers types declare it, but the DOM lib's `SubtleCrypto` type wins in
  this project and hides it, so `src/env.d.ts` adds the one method back.
- **Products with orders stay in their round.** Order items point to the
  round's product row, so removing it would break them. The delete has a
  `NOT EXISTS (order item)` condition, and the page shows the checkbox as
  ticked and disabled, with a hidden field so the form still sends it. Added
  to plan section 8.
- **Opening a round checks that it exists first.** The walk found that opening
  a missing round id closed the open round and left none open. Now it answers
  "Zapisa ni več. Osvežite stran." and changes nothing (test added).
- **404 on an admin page**: Astro renders the 404 page in a second pass with
  the same URL, and the guard redirected that pass to login. The middleware
  now lets the 404 route through (it is a public page with no data).
- **Form values after an error**: the page reads `Astro.request.formData()`
  again, so everything typed stays, including blank lines in textareas.
  Checked in `astro dev` and `astro preview`.
- **Logout** redirects to login only when the action succeeded; otherwise
  back to `/admin`, so a failed logout never looks like a successful one.
- **Slug**: empty means it is made from the name (`Domači jogurt` becomes
  `domaci-jogurt`). A taken slug is an error, not silently changed.
- **Prices** accept a comma or a dot, up to 9999,99. Zero is allowed.
- **Phone layout**: on the round page the checkbox sits in the product cell
  (the name is its label) and "Naročeno" sits under the name, so the table
  has three columns and fits 390 px. The product list shows the unit under
  the name; the list order is the sort order.
